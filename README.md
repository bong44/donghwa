# 동화약품 활명수 영업 자료

활명수 유와 꼬마활명수의 휴가철 특별 가격을 안내하는 모바일 중심 영업 페이지입니다.

- 진입점: `index.html`
- 제품 이미지: `제품별이미지/활명수 유.jpg`, `제품별이미지/꼬마활명수.jpg`
- 이전 컴배트 페이지: `이전버전/index_컴배트_2026-08-12.html`

## 현재 판매 조건

- 두 제품 모두 1박스 10개입
- 최소 주문: 제품별 2박스(20개)
- 20개 구매 시 개당 2,970원
- 60개 구매 시 개당 2,640원
- 한 제품을 20개 이상 구매하면 비닐봉투 100장 제공
- 서로 다른 제품의 수량은 사은품 기준에 합산하지 않음

## 배포

기존과 동일하게 GitHub Pages에서 `index.html`을 정적 페이지로 배포합니다.
